# Security

This is demo code. It is not hardened for production use and ships with an
unauthenticated `/api/signals/attributes` proxy so the on-page debug panel can
read a session's own attributes. Deploy it only against demo data.

To report a vulnerability in this repository, use GitHub's private
reporting: **Security → Report a vulnerability** on the repo page. Please
include the file and a reproduction. Don't open a public issue.
